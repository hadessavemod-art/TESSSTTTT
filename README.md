# Школьный навигатор №60

Интерактивный веб-путеводитель по **МБОУ «СОШ № 60» города Новокузнецка** (индивидуальный школьный проект для допуска к ОГЭ).

## Дизайн и архитектура

- **Визуальное направление:** Premium Minimalism — светлая основа (`#FFFFFF` / `#F5F5F7`), чёткая типографика (`Inter` с табличными цифрами `tabular-nums`), акцентный навигационный синий (`#0071E3`), сегментированные переключатели и тонкие разделительные линии без визуального шума.
- **Плоская структура для GitHub Pages:** все файлы размещены в корне репозитория без вложенных папок.

## Состав файлов

- `index.html` — главная страница с архитектурным обзором, живым статусом учебного дня и редакционным представлением проекта.
- `teachers.html` — каталог всех 40 сотрудников школы из официального документа с живым поиском, фильтрацией и переходом к кабинету на карте.
- `map.html` — интерактивная поэтажная схема школы (1–4 этажи) с подсветкой помещений и карточкой закреплённых педагогов.
- `schedule.html` — расписание звонков с таймером обратного отсчёта и автоматическим выделением текущего и следующего уроков.
- `style.css`, `responsive.css` — стили и адаптивность под все разрешения (1920px → 360px).
- `data.js`, `app.js` — единая база данных и логика интерфейса.
- `.nojekyll` — служебный файл для корректной публикации статических файлов на GitHub Pages.
