# Школьный навигатор №60

Интерактивный веб-путеводитель по **МБОУ «СОШ № 60» города Новокузнецка** (индивидуальный школьный проект для допуска к ОГЭ).

## Основные возможности

1. **Главная страница (`index.html`)** — презентация проекта, живая строка состояния учебного дня, описание решаемой проблемы и официальная справка о школе.
2. **Педагогический состав (`teachers.html`)** — цифровой справочник всех 40 сотрудников школы из официального документа с поиском по ФИО, предмету и кабинету, фильтрацией и прямым переходом к кабинету на карте.
3. **Интерактивная карта школы (`map.html`)** — поэтажная схема (1–4 этажи), переключение этажей, поиск кабинета по номеру или по фамилии преподавателя, подсветка помещения и просмотр закреплённых сотрудников.
4. **Расписание звонков (`schedule.html`)** — временная сетка уроков и перемен на основе фотодокумента школы с автоматическим выделением текущего/следующего урока и живым таймером обратного отсчёта.

## Источники данных

- Официальный документ «Педагогический состав школы 60» (40 сотрудников).
- Фотография расписания звонков МБОУ «СОШ № 60» (сетка «Пятница», 10 уроков).
- Официальные сведения МБОУ «СОШ № 60» г. Новокузнецка: [shkola60-kuz.kemobl.ru](https://shkola60-kuz.kemobl.ru/) (ул. Дузенко, д. 14А).

## Технологии и структура

Проект построен на чистом **HTML5, CSS3 и Vanilla JavaScript** без сборщиков и внешних зависимостей. Все файлы располагаются строго в корне репозитория для удобной загрузки через веб-интерфейс GitHub и публикации на GitHub Pages.
